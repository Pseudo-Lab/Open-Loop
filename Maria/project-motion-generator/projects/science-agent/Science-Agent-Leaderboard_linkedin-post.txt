Meet 𝗦𝗰𝗶𝗲𝗻𝗰𝗲 𝗔𝗴𝗲𝗻𝘁 𝗟𝗲𝗮𝗱𝗲𝗿𝗯𝗼𝗮𝗿𝗱, a Pseudo Lab community project building a public benchmark and leaderboard for agents that solve science problems.

A run that exits cleanly isn't a result. If the official metric is missing or invalid, the run fails. Only runs that pass every check reach the board.

🔍 What do we evaluate?
Not just the model, but the agent's design:
- Correctness
- Tool use
- Cost
- Reproducibility

🔄 How does a run reach the board?
Define the task → isolate the run → run the agent → validate the schema → check the official metric → publish to the board.
Every run gets its own workspace, and no state carries over from earlier runs.

✅ Built so far: a public challenge, an evaluation framework, an isolated run pipeline and a leaderboard MVP.
➡️ Next: more science tasks and models, multi-agent benchmarks, and exploring autonomous research agents inspired by AutoResearch. From agents that search to agents that research.
